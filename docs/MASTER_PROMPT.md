# JARVIS Mobile — instrucciones vigentes

Continúa como aplicación nativa Android/iOS con React Native, Expo, Expo Router y TypeScript. Trabaja en la raíz existente. No crear app anidada, repositorio nuevo, versión web ni WebView. No hacer commits automáticamente.

Consulta google_stitch, proyecto **JARVIS Student Command Center**, ID 11174925214121356476, al implementar pantallas. Conserva referencias actuales, jerarquía, paleta oscura, tipografías y navegación. HTML solo como referencia.

Usa StyleSheet y src/theme/tokens.ts. Inter, Space Grotesk y JetBrains Mono locales. Cinco pestañas: Inicio, Tareas, JARVIS central destacado, Agenda y Perfil. Contenido vertical, controles táctiles de 48 puntos, safe areas, teclado y fuentes escalables.

Mantén UI, dominio, datos y asistente separados. Reutiliza prioridad explicable, briefing, agenda y dinero exacto. SQLite con migraciones y validación; AsyncStorage para preferencias. Demo local sin backend ni claves. Etiqueta datos y fecha de demostración.

Sigue IMPLEMENTATION_PLAN.md por fases. Foundation y Home tienen portado inicial. Verifica en Expo Go cuando sea posible y continúa los flujos académicos; después finanzas, sistema personal e inteligencia.

Inteligencia: contexto relevante → intención → consulta/propuesta → respuesta. Proveedor determinista identificado; no simular LLM, voz, sincronización ni historial persistente. Las sugerencias explican sus motivos y las acciones sensibles requieren confirmación.

Cada control disponible debe funcionar. No usar placeholders o éxitos ficticios para funciones pendientes. Mantener estados de carga, error, vacío y feedback.

Al terminar cada fase: typecheck, lint, pruebas pertinentes, exportación Android/iOS y Expo Doctor. Registrar qué se probó en dispositivo y qué sigue pendiente; un bundle no es prueba visual. Actualizar arquitectura, sincronización Stitch, decisiones y plan.

Continuar autónomamente en decisiones reversibles. Preguntar solo por bloqueos reales. Resumen final: IMPLEMENTED, CHANGED, TESTED, STITCH SYNC, EXPO STATUS, NEXT PHASE y BLOCKERS.
